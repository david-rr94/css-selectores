# 🎨 Práctica de Selectores CSS

Repositorio de ejercicios del módulo CSS del Máster Full Stack (ConquerBlocks).

## Cómo usarlo

1. Abre `index.html` con **Live Server** en VS Code
2. Abre `selectores.css` en el editor
3. Lee cada ejercicio (están como comentarios)
4. Escribe el **selector CSS** correcto donde pone `TU RESPUESTA ↓`
5. Si el selector funciona, verás el elemento cambiar de color en el navegador
6. Haz commit cuando termines cada bloque

## Estructura

```
css-selectores/
├── index.html       ← HTML con todos los elementos a seleccionar
├── selectores.css   ← Aquí escribes tus respuestas
└── README.md
```
